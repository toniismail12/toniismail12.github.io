Enterprise Single Sign-On Platform

Flagship

Satu gerbang identitas untuk seluruh aplikasi internal PT Pusri. Realm, client, dan role mapping Keycloak dirancang sebagai sumber identitas tunggal, menghapus pengelolaan kredensial di tiap aplikasi. Alur Authorization Code dan validasi JWT distandardisasi di sisi resource server, lengkap dengan refresh token, session validation, dan single logout.

  • Passkeys/WebAuthn dan OTP via WhatsApp sebagai faktor login alternatif untuk pengguna non-desktop.
  • RBAC dipetakan ke struktur organisasi — unit kerja dan jabatan — sehingga otorisasi mengikuti hierarki perusahaan tanpa konfigurasi manual.
  • Diperluas ke IAM mobile dan portal web IAM dengan kebijakan otorisasi yang sama.

Alur investasi rutin end-to-end: usulan → realisasi → disbursement → relokasi anggaran, dengan tabel riwayat terpisah yang merekam jejak audit setiap perubahan nilai.

SIHPP — Sistem Harga Pokok Produksi

Backend perhitungan harga pokok produksi untuk tiga lini produk — Urea, Amoniak, NPK — mencakup proyeksi versus realisasi produksi dan seluruh komponen biaya: biaya tetap, bahan baku, utilitas, ratio rendal, serta biaya usaha dan keuangan.

  • Arsitektur berlapis handler–service–repository dengan envelope respons JSON konsisten, sehingga menambah modul produk baru tidak menyentuh kode modul lain.
  • Migrasi skema dan seeding master data berjalan otomatis saat startup — tidak ada langkah setup manual di environment baru.
  • Swagger UI dengan Try it out sebagai kontrak API resmi bagi tim frontend.
